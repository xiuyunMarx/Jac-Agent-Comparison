# JacAgentComparison -- the primary environment.
#
# Five benchmarks, each implementing one agent three ways (Jac/byLLM, an agent
# framework, a plain OpenAI-SDK baseline). These pins are the versions the
# comparison was last run against, not floors: an agent framework's behaviour
# changes between minor releases, and an unpinned re-run measures the upgrade
# rather than the framework.
#
#   conda create -n jaseci python=3.13 && conda activate jaseci
#   pip install -r requirements.txt
#
# Python 3.13.x. Not 3.14: the two CrewAI arms require <3.14. Not 3.12 or
# lower: YTNavigator/YT-Navigator declares >=3.13.2.
#
# ---------------------------------------------------------------------------
# What pip cannot install for you
# ---------------------------------------------------------------------------
#
#   jac         The Jac toolchain, which ships its own Python. Packages you pip
#               install here are NOT visible to it -- run `jac install` once in
#               each Jac project instead:
#                 CodeAgent/byLLM, Email-Auto-response/byLLM,
#                 meeting-assistant/byLLM, YTNavigator/byLLM,
#                 RagGPT/Jac-Rag-GPT, RagGPT/Jac-Rag-GPT-ByllmRouter
#   ollama      The model server (https://ollama.com/download), or any other
#               OpenAI-compatible endpoint via $BENCH_BASE_URL.
#   udocker     Installed below, but needs `udocker install` once before
#               CodeAgent can pull a SWE-bench image. `docker` works too.
#   postgres    YTNavigator needs Postgres with pgvector. Its eval starts one
#               itself from any conda env that has the binaries:
#                 conda create -y -n ytnav-pg -c conda-forge postgresql pgvector
#
# The Email CrewAI arm is NOT installable here -- see requirements-email-crewai.txt.
# ---------------------------------------------------------------------------

# -- byLLM ------------------------------------------------------------------
