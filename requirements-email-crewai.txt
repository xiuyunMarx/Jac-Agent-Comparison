# Email-Auto-response/CrewAI-LangGraph -- its own environment, deliberately.
#
# This arm pins langgraph 1.x. CodeAgent/langgraph and YTNavigator/YT-Navigator
# pin langgraph 0.3.5. There is no version that satisfies both, so this one arm
# runs from its own virtualenv and everything else runs from the primary one.
# eval/run.py finds it automatically at CrewAI-LangGraph/.venv/bin/python.
#
#   cd Email-Auto-response/CrewAI-LangGraph
#   python3.12 -m venv .venv               # crewai needs Python <3.14 (e.g. /usr/bin/python3.12)
#   .venv/bin/pip install -r ../../requirements-email-crewai.txt
#
# Nothing else in the repo imports from this environment, and this environment
# needs nothing else from the repo: the arm reaches the shared mock_mailbox by
# sys.path, not by installation.

# crewai 1.x drives tools through the provider's native function calling
# (agents/crew_agent_executor.py: check_native_tool_support). 0.130's text
# ReAct protocol relied on a `\nObservation:` stop sequence; GLM 5.2 on
# ollama.com ignores stop, writes the Observation itself and declares "all
# drafts created" without ever calling a tool (0 drafts, 3 calls per batch).
